# 樱聘 YingPin — 中国人向け特定技能求人サイト（モック＋β版計画）

> 📐 **β版（実際に動く会員登録＋管理画面）の設計計画書**: [docs/beta-plan.md](docs/beta-plan.md)（図入り）／作業チケット: [docs/tasks.md](docs/tasks.md)／開発規約: [AGENTS.md](AGENTS.md)・[CLAUDE.md](CLAUDE.md)

日本で働きたい／既に働いている20〜30代の中国人をターゲットにした、特定技能専門求人サイトの**デザイン確認用モック**です。ビルド不要の静的HTML+CSS+JSで構成されており、ブラウザで開くだけで動作します。

> ⚠️ 本モックに掲載されている求人・企業・数値・WeChat IDはすべてサンプル（ダミー）です。認証やデータ保存はブラウザ内（localStorage）でのシミュレーションのみ行います。

## 見方

いずれかの方法で開けます。

1. **そのまま開く** — `index.html` をダブルクリックしてブラウザで開く
2. **1ファイル版** — `preview.html` は全画面を1つのHTMLに束ねた自己完結版。このファイル1つを渡すだけで共有できます（`node tools/build-preview.js` で再生成）
3. **ローカルサーバ** — `python3 -m http.server 8000` を実行して `http://localhost:8000` を開く
4. **GitHub Pages** — リポジトリの Settings → Pages でブランチを公開すると、スマホ実機からもURLで確認できます

スマホ表示（幅480px以下）を前提にデザインしています。PCで開いた場合は中央にアプリ枠が表示されます。

## モック用の操作パネル

画面右下の **⚙ ボタン** から、モック確認用の設定を切り替えられます（実サイトには表示されない想定）。

| 設定 | 内容 |
|---|---|
| デザインテーマ | 🌊 トラストブルー（デフォルト）⇄ 🌸 小紅書風レッド を即時切替（全画面共通） |
| 表示言語 | 日本語 ⇄ 简体中文 を即時切替（最終実装は中国語のみを想定） |
| 登録状態リセット | 会員登録済み状態を解除して未登録の初期状態に戻す |

## 画面と主な機能

| 画面 | ファイル | 内容 |
|---|---|---|
| ランディング | `index.html` | サービス紹介。未登録時は求人がぼかし＋🔒のロック表示で「登録すると見られる」ことを訴求 |
| 新規登録 | `register.html` | 4ステップウィザード（基本情報→連絡先(電話・WeChat)→取得資格→確認）→ 会員ID発行の完了演出 |
| ログイン | `login.html` | モックのため任意入力でログイン成功（デモ用プロフィールが入ります） |
| 求人一覧 | `jobs.html` | キーワード検索／**特定技能2号移行対象11分野**チップ／エリア（地方）／こだわりタグで絞り込み。未登録時は全件ロック |
| 求人詳細 | `job.html?id=1` | 労働条件（給与・時間・休日・住まい・福利厚生・応募条件）と匿名の企業情報。応募／WeChat相談／お気に入り |
| お気に入り | `favs.html` | ♡した求人の一覧 |
| マイページ | `mypage.html` | 登録情報の確認・応募履歴・言語/テーマ設定・ログアウト |

- 求人情報は企業が特定されない粒度（業種・規模・エリアのみ。社名は「応募後開示」の建付け）
- 対象分野は特定技能2号へ移行できる11分野のみ（介護は2号対象外のため除外）

## ファイル構成

```
├── index.html / register.html / login.html
├── jobs.html / job.html / favs.html / mypage.html
├── preview.html            # 1ファイル版（自動生成物。編集はtools/側で）
├── tools/
│   ├── build-preview.js    # preview.html を生成するスクリプト
│   └── preview-views.js    # 1ファイル版用のルーター＆画面定義
├── assets/
│   ├── css/style.css      # 全スタイル（2テーマはCSS変数 [data-theme] で切替）
│   └── js/
│       ├── i18n.js        # 日本語/简体中文の文言辞書（キーで一元管理）
│       ├── data.js        # 11分野マスタ＋サンプル求人14件（ja/zh併記）
│       └── app.js         # テーマ・言語・登録状態・共通UI（タブバー/モーダル/カード等）
└── README.md
```

## データ・文言の編集

- **求人を増やす/直す** → `assets/js/data.js` の `JOBS` 配列に追記（`{ ja, zh }` 併記）
- **文言を直す** → `assets/js/i18n.js` のキーを編集。画面側は `data-i18n` 属性か `t('キー')` で参照
- **色・角丸などの調整** → `assets/css/style.css` 冒頭のテーマ変数（`[data-theme="red"]` / `[data-theme="blue"]`）

## 本実装に向けたメモ

- 最終実装が中国語のみで良い場合は、`i18n.js` の `zh` 辞書をベースにそのまま置き換え可能
- 認証・会員情報・求人データはバックエンド（DB＋API）に置き換える前提。localStorageのキー（`yp_*`）が置き換えポイント
- 実装フレームワークへ移行する場合も、本モックのCSS変数・コンポーネント構造（カード/チップ/シート等）は流用可能
- 実運用時の検討事項：WeChat公式アカウント連携、SMS認証（+86/+81）、個人情報の取扱い（要プライバシーポリシー）、中国国内からのアクセス速度（フォント・CDN）
