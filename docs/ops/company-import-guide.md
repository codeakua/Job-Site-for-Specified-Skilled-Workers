# 企業管理（求人企業マスタ）の導入手順書（オーナー向け）

最終更新: 2026-08-01（T-18 企業管理の導入時に作成）

## これは何をする機能か

- パートナー協同組合の**企業データベース（約100社）をサイトに登録**し、管理画面に「🏢 企業管理」を追加します
- **求人票に「どの企業の求人か」を紐づけられる**ようになります（求人一覧・応募一覧にも企業名が出ます）
- 企業一覧は**CSVでダウンロード**でき、Excelでそのまま開けます（文字化けしません）
- 各企業には、組合の**雇用条件書データベース由来の実際の労働条件**（月給・手取り・控除・休日数・寮の家賃など）も参考値として入っています

> 🔒 **会員側（求人サイト）には一切表示されません。** 企業テーブルはスタッフだけが読める設定（RLS）で、会員がブラウザから直接データベースに問い合わせても**1行も見えません**（ローカル環境で実証済み）。求人票の見た目は今までと同じ「匿名の企業プロフィール」のままです。

## 適用手順（3ステップ・順番が大事）

> ⚠️ **必ず「SQL → データ投入 → マージ」の順で行ってください。**
> 新しいアプリは企業テーブルを読みに行くため、SQLより先にマージすると、SQLを流すまでの間だけ管理画面の求人一覧が表示できなくなります。

### ① 0006 のSQLを実行する（テーブルを作る）

1. Supabase の **SQL Editor** → **+ New query**
2. `app/supabase/migrations/0006_companies.sql` の中身をすべてコピーして貼り付け → **Run**
3. 確認クエリを実行して、期待値どおりか確認：

```sql
select
  (select count(*) from information_schema.tables
     where table_schema='public' and table_name='companies')                     as "① 企業テーブル(期待値 1)",
  (select count(*) from pg_policies where schemaname='public')                   as "② アクセス制御ルール(期待値 16)",
  (select count(*) from pg_policies
     where schemaname='public' and tablename='companies')                        as "③ 企業のルール(期待値 1)",
  (select count(*) from information_schema.columns
     where table_schema='public' and table_name='jobs'
       and column_name='company_id')                                             as "④ 求人の紐づけ列(期待値 1)";
```

→ **1 / 16 / 1 / 1** になれば成功。

### ② 企業データの投入SQLを実行する

1. Claudeからチャットで受け取った **`import_companies.sql`** の中身をすべてコピーして、SQL Editor に貼り付け → **Run**
   - このファイルは**実在の企業名・個人名を含むため、GitHubリポジトリには置いていません**（チャットでの受け渡しのみ）
   - **誤って2回実行しても大丈夫**です（同じ社名は追加されない作り ＝ `on conflict do nothing`）。あとから管理画面で修正した内容が上書きされることもありません
2. 確認：

```sql
select count(*) from companies;
```

→ 受け渡し時に伝える**期待件数**と一致すれば成功。

### ③ PRをマージする（画面が使えるようになる）

マージ＝デプロイ後、以下を実機で確認：

1. `/admin` を開く → サイドバーに **「🏢 企業管理」** がある／ダッシュボードに **「登録企業」** の枚数が出る
2. **企業管理** を開く → 全社が一覧に出る。検索（社名・担当者など）と絞り込み（契約状況・受入業種）が効く
3. **「⬇ CSVダウンロード」** → Excelで開いて日本語が化けていない・全社入っている
4. **求人管理 → 求人を編集** → 「企業情報」セクションの **「求人企業」** で企業を選んで保存 → 求人一覧の「企業」列に社名が出る
5. **応募管理** → 求人名の下に企業名（🏢）が出る（企業を紐づけた求人への応募のみ）
6. **会員側の確認**: 求人一覧・求人詳細に企業名が出ていないこと（今までどおり匿名プロフィールのみ）

## ふだんの使い方

- **新しい企業が組合に加入したら**: 企業管理 → 「＋ 新規登録」で追加（社名だけでも保存できます）
- **求人票を作るとき**: 求人フォームの「求人企業」でその企業を選ぶ → どの企業の求人か管理画面で分かるようになります。企業の編集画面には「この企業の求人」一覧も出ます
- **企業情報を直したいとき**: 一覧から社名をクリックして編集。労働条件・賃金の欄は**雇用条件書からの自動抽出値（参考）**なので、間違いを見つけたら原本（雇用条件書）を確認のうえここで修正してください
- **削除ボタンはありません**: 契約が終わった企業は「契約状況」欄を書き換えて残します（求人票との紐づけ履歴を守るため）。どうしても消す場合はSQLで削除でき、その企業に紐づいていた求人は「企業未設定」に戻るだけで消えません

## 注意（データの性質）

- 電話番号・メールアドレスの欄は**元データに無いため空**です。分かり次第、編集画面で入力してください
- CSVをExcelで開くと、**先頭が0の電話番号は0が消えて見える**ことがあります（Excelの表示仕様。データ自体は壊れていません）
- 労働条件の数値は契約書からの自動抽出のため、**まれに抽出ミスがあります**（元のExcelにも「最終確認には元書面をご参照ください」と注記があります）

## 再取込について（将来）

組合の企業データベースが大きく更新されたときは、Claudeに「企業データを取り込み直したい」と伝えてください。**同名企業は追加されない仕組み**のため、新規加入企業だけが追加されます（既存企業の一括更新が必要な場合は、その時点で専用のSQLを別途作ります）。
