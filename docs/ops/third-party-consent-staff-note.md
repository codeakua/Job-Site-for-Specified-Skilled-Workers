# 求人企業に会員の情報を渡すときのルール

> **この資料は、職業紹介を担当する社員の方に向けたものです。** 専門知識は必要ありません。
> **読む時間: 10分。** 実際の作業は、会員1人・企業1社あたり5〜10分です。
> 迷ったときは、**送る前に必ず止めて**上長に相談してください。**送ってしまってからでは取り返せません。**

---

## 1. まず、これだけは覚えてください

### 🚨 「応募があった」は「情報を渡してよい」という意味ではありません

会員が求人に応募するのは、**「この仕事に興味があります」と手を挙げた**だけです。
**「この会社に、私の名前と生年月日を教えていいですよ」とまでは言っていません。**

ですから、応募があっただけの状態で企業に会員の情報を送ると、**法律違反になります。**

情報を渡す前に、**その会員から、その企業について、個別に「同意します」をもらう**必要があります。

### なぜそこまで厳しいのか

| 理由 | 内容 |
|---|---|
| **法律** | 個人情報保護法は、**本人の同意なしに他社へ個人情報を渡すこと**を禁止しています |
| **会社の許可** | 当社は**有料職業紹介事業の許可（11-ユ-301340）**を受けて営業しています。個人情報の扱いに問題があると、**許可そのものに関わります** |
| **会員との約束** | サイトに掲示しているプライバシーポリシーで、「**同意は求人企業ごとに取得します**」と会員に明言しています。守らなければ約束違反です |

---

## 2. 覚えるルールは3つだけ

```
ルール1  企業ごとに、そのつど同意をもらう
ルール2  「同意します」と文字で返事が来るまで、絶対に送らない
ルール3  もらった同意は、その場で記録する
```

### ルール1: 企業ごとに、そのつど同意をもらう

「これから紹介する会社すべてについて、まとめて同意してください」は **できません。**
A社に紹介するときはA社について、B社に紹介するときはB社について、**別々に**同意をもらいます。

### ルール2: 「同意します」と文字で返事が来るまで、絶対に送らない

| 会員の反応 | 同意として扱えるか |
|---|---|
| 「同意します」「はい、お願いします」「同意」 | ✅ **同意です** |
| 既読がついただけ | ❌ 同意ではありません |
| スタンプ・絵文字だけ | ❌ 同意ではありません（何への返事か分からないため） |
| 「考えます」「あとで返事します」 | ❌ まだ同意ではありません |
| 何も返事がない | ❌ 同意ではありません |
| 電話で「いいですよ」と言われた | ❌ **証拠が残らないので使えません。** WeChatで送り直して、文字で返事をもらってください |

「たぶん大丈夫です」のような**あいまいな返事**が来たら、もう一度はっきり聞き直してください。

### ルール3: もらった同意は、その場で記録する

**記録が、後から「ちゃんと同意をもらっていた」ことを示す唯一の証拠**になります。
「あのとき確かに同意をもらった」という**記憶や口頭の説明は、証拠になりません。**

記録は管理画面の「応募管理」の**スタッフメモ**に書きます（書き方は §5）。

## 3. 全体の流れ

```
①紹介するか決める → ②会員に同意をお願いする → ③返事を待つ → ④記録する → ⑤企業へ渡す

                                              ↑
                            ここで「同意します」が来るまで、④⑤へ進まない
```

| ステップ | やること | どこで |
|---|---|---|
| ① | 応募を見て、その企業に紹介するか判断する | 管理画面「応募管理」（ステータス「新規」） |
| ② | 会員に同意のお願いを送る | WeChat（文面は §4） |
| ③ | 「同意します」の返事を待つ | WeChat |
| ④ | 同意をもらったことを記録する | 管理画面「応募管理」のスタッフメモ（§5） |
| ⑤ | 企業へ情報を渡し、ステータスを進める | メール等 ／ 管理画面 |

---

## 4. 渡してよい情報・渡してはいけない情報

渡してよい情報は**2段階に分かれています。**

| 段階 | いつ渡すか | 渡してよい情報 |
|---|---|---|
| **第1段階** | 紹介すると決めたとき | 氏名、拼音、生年月日、性別、国籍、居住地（日本／中国）、日本語能力（JLPT）、合格済みの特定技能分野、その他の資格・技能、**当社が作成した紹介状** |
| **第2段階** | **面接をすることが決まってから** | 上に加えて、**電話番号・WeChat ID** |

### ⚠️ 第2段階を先にやらないでください

連絡先（電話番号・WeChat ID）を早く渡してしまうと、**企業から会員へ直接連絡が行き、当社が把握できないやり取りが始まります。** 条件の食い違いや、会員が不安になるトラブルの元になります。

**面接が決まってから、あらためて同意をもらってください。**

### ⚠️ 上の表にないものは渡さない

| 渡してはいけないもの | 理由・代わりにどうするか |
|---|---|
| **住所** | 表にありません。面接会場を決めるのに必要なら、**「都道府県までお伝えしてよいですか」と会員に確認**してください |
| **メールアドレス** | 表にありません |
| **他社の選考状況・応募履歴** | 会員の不利益になります |
| **本人確認のWeChatのやり取りそのもの** | 必要な情報だけを抜き出して伝えてください |
| **パスワード** | **そもそも当社も知りません。** 誰にも読めない形で保管されています |

## 6. 記録の書き方（そのままコピーして使えます）

管理画面「応募管理」で該当の応募を開き、**スタッフメモ**に**1行1件で追記**します。
**前の行を消したり書き換えたりせず、下に足していってください。**

```
[同意依頼] 2026-08-20 14:30 / 企業=○○株式会社 / 就業場所=埼玉県富士見市 / 段階=第1段階 / 経路=WeChat
[同意取得] 2026-08-20 16:05 / 企業=○○株式会社 / 段階=第1段階 / 会員の返答=「同意」 / 担当=矢澤
[提供実施] 2026-08-20 17:20 / 企業=○○株式会社 / 項目=氏名・拼音・生年月日・性別・国籍・居住地区分・日本語能力・特定技能分野・その他資格・紹介状 / 方法=メール / 送付先=採用担当 ××様
```

### なぜこの書き方なのか

- **「いつ・どの企業に・何を・どうやって同意を得たか」が1行で分かります。** 会員から問い合わせがあったときも、行政や弁護士に確認されたときも、これを見せれば答えられます
- **「依頼」「取得」「実施」を分けて書く**ので、**同意をもらう前に送っていないか**が一目で分かります
- この記録は**2年間保存**します（職業安定法で定められています）

### 書き間違えたときは

**前の行を消さないでください。** 下に訂正の行を足します。

```
[訂正] 2026-08-21 09:00 / 上記「提供実施」の送付先は ××様ではなく △△様の誤りでした / 記入=矢澤
```

> **記録を後から書き換えると、記録そのものの信用がなくなります。** 「都合が悪くなったら直せる記録」は、証拠として認められません。

## 7. こんなときどうする（早見表）

| こんなとき | どうする |
|---|---|
| **会員が断った** | その企業への紹介はしません。**他の求人への応募は今までどおりできます**（そう伝えてください）。応募のステータスを「辞退」にして、メモに理由を書きます |
| **返事が来ない** | **3営業日**待って、1回だけ確認の連絡を入れます。それでも返事がなければ紹介を見送ります。**黙って送ることは絶対にしません** |
| **「連絡先は渡したくない」と言われた** | 同意された情報だけを渡します。**面接の日程は当社が間に入って調整**します |
| **企業から「まず候補者の情報を送って」と求められた** | **同意をもらう前は送れません。** 「同意を確認してからお送りします」と伝えてください。年齢・性別・資格だけの匿名の紹介であっても、**氏名・生年月日・拼音を含めた時点で「個人情報を渡した」ことになります** |
| **会員が「やっぱり取り消したい」と言ってきた（まだ送っていない）** | 送りません。メモに記録します |
| **会員が「やっぱり取り消したい」と言ってきた（もう送った）** | **すぐに企業へ連絡し、情報の利用停止と削除を依頼**します。依頼した日時と相手の名前をメモに記録します。**自己判断で放置しないでください** |
| **同じ会員を、別の企業にも紹介したい** | **その企業について、あらためて同意をもらいます**（ルール1） |
| **急いでいるので先に送ってしまいたい** | **できません。** 急ぐ場合は、会員に電話をして「いまWeChatを送ったので確認してください」と伝え、返事を早めてもらってください |

---

## 8. やってはいけないこと（5つ）

1. **応募があったことを、同意とみなす**
2. **「今後すべての企業について同意します」とまとめて同意をもらう**
3. **§4の表にない情報を渡す**（特に住所・メールアドレス）
4. **同意の記録を後から書き換える・消す**
5. **電話や口頭だけで同意を取る**（証拠が残りません）

---

## 9. 困ったときは

- **判断に迷ったら、送る前に止めて上長に相談してください。** 遅れて怒られることはありますが、**送ってしまうと取り返せません**
- **すでに送ってしまった、間違えて送ったと気づいたときは、隠さずすぐに報告してください。** 早く分かれば、企業に削除を依頼するなど手が打てます
- 苦情・お問い合わせの窓口: **yazawa-y@partner-japan.biz**（株式会社パートナー 職業紹介責任者）

## 付録: この資料の根拠

この資料は、社内の正式な手順書 `docs/ops/third-party-consent-guide.md` を、**分かりやすさを優先して書き直したもの**です。内容は同じです。根拠となる条文まで確認したい場合は、そちらをご覧ください。

| 根拠 | 内容 |
|---|---|
| 個人情報保護法 第27条 | 本人の同意なく個人情報を第三者に提供してはならない |
| 職業安定法 第5条の3 | 職業紹介にあたり、労働条件（業務内容・契約期間・就業場所・賃金・労働時間・社会保険・受動喫煙防止措置）を明示する |
| 職業安定法 第32条の15 | 求人求職管理簿を**2年間**保存する |
| プライバシーポリシー 第4条第2項・第3項 | あらかじめ会員の同意を得たうえで、決められた範囲の情報を提供する。**同意は求人企業ごとに取得する** |
| 利用規約 第11条 | 実際の雇用主の名称・就業場所は職業紹介の段階で会員に明示し、あらかじめ同意を得て情報を提供する |

プライバシーポリシーと利用規約は、サイトの一番下（フッター）からいつでも読めます。

> **なお、「登録のときに一度まとめて同意をもらう形でよいか」は、現在、顧問弁護士に確認中です。** 「それでよい」との回答があれば、この手順は簡単になります。**回答が来るまでは、この資料のとおり企業ごとに同意をもらってください。**
