# おかしくなったときに元へ戻す手順（オーナー用・専門知識不要）

> **このページの目的**: サイトを更新したあと表示が壊れた・動かなくなったとき、**オーナーが1人で、1分で元に戻す**ための手順です。
>
> 🔴 **8/8までに一度、実際に練習しておいてください。** 本番で慌てているときに初めて操作する、という状況を避けるためです（練習しても害はありません）。
>
> 迷ったら、**いま見えている画面の文字をそのままClaudeに伝えてください**（スクリーンショットでもOK）。

---

## まず落ち着いて — 判断のしかた

| 症状 | やること |
|---|---|
| マージした直後、Vercelの画面が **`Error`（赤）** | **何もしなくて大丈夫です。** 本番は前のまま動いています。画面をClaudeに伝えてください |
| マージして `Ready`（緑）になったが、**サイトの表示が壊れた／動かない** | 👉 **下の「手順A」で戻す** |
| サイトは動くが、一部の表示がおかしい | 緊急でなければClaudeに伝えて直します。急ぐなら手順A |
| Supabaseで**SQLを実行したあと**におかしくなった | 👉 **手順Aでは戻りません。** 下の「⚠️ データベースは戻らない」を読んでください |

---

## 手順A：ひとつ前の状態に戻す（1分・オーナー1人でできる）

これが **オーナーが単独でできる唯一の復旧方法**です。

1. **Vercel** にログインし、このサイトのプロジェクトを開きます。
   ```
   https://vercel.com/dashboard
   ```
2. 上部のタブから **Deployments**（デプロイ履歴）を開きます。
3. 一覧から、**いま動いているもの（最上段）のひとつ下**にある、**`Ready`（緑）** のものを探します。
   - 「壊れる前に正常に動いていたもの」を選びます。日時を目安にしてください。
4. その行の右端にある **「…」（three dots）** を押します。
5. **`Promote to Production`**（本番に昇格）を選びます。
   - ※画面によっては **`Rollback`**（ロールバック）と表示されることがあります。どちらでも同じ意味です。
6. 確認のダイアログが出たら実行します。**30秒ほどでサイトが元の状態に戻ります。**
7. `https://yingpin.jp` を開いて、直ったことを確認します。

---

## ⚠️ 戻したあとに必ずやること

### 1. Claudeに連絡してください（これが重要です）

**手順Aで戻るのは「表示されているサイト」だけで、GitHub側の記録は元に戻りません。**

そのため、**次に何かをマージした瞬間に、壊れたコードがもう一度反映されます。**

> 「〇月〇日 〇時ごろにマージした△△のあと、□□が壊れたのでVercelで巻き戻しました」

とだけ伝えてください。原因を直して、正しい状態に戻します。**それまでは新しいマージをしないでください。**

### 2. ⚠️ データベースは戻りません

Vercelの巻き戻しで戻るのは **サイトのプログラム（見た目と動き）だけ**です。

**Supabaseに入っている会員・求人・応募のデータや、SQLで変えた設定は戻りません。**

SQLを実行したあとに問題が起きた場合は、**そのSQLファイルの末尾に「元に戻すためのSQL」がコメントで書いてあります**。ただし**自己判断で実行せず、必ずClaudeに相談してください**（実行の順序を間違えると、かえって壊れることがあります）。

---

## 手順B：Claudeが打ち消しの変更を出す（時間がかかる）

手順Aで足りないとき、または根本的に直したいときはこちらです。**オーナー1人ではできません**（Claudeの作業が必要です）。

1. Claudeが「打ち消すためのPR」を作ります
2. 自動チェック（CI）が緑になるのを待ちます（3〜5分）
3. オーナーがマージします
4. Vercelが自動で反映します（2〜3分）

**合計10分ほどかかり、Claudeが対応できる時間帯である必要があります。** だからこそ、まず手順Aを使ってください。

---

## 練習のしかた（8/8までに1回）

**壊さずに練習できます。**

1. Vercel → Deployments を開く
2. 最上段のひとつ下の `Ready` の行で「…」を押す
3. **`Promote to Production` というメニューがあることを目で確認する**（ここでは押さない）
4. メニューを閉じる

これだけで十分です。**「どこに何があるか」を知っていれば、本番で迷いません。**

余裕があれば、実際に一度戻して、また最新に戻す（最上段を `Promote`）まで試しておくと確実です。
