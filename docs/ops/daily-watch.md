# 毎営業日の見張り（1分でできる確認）

> **このページの目的**: サイトが静かに壊れていないかを、**毎朝1分だけ管理画面を見て**気づけるようにします。
>
> 🔴 **このサイトには、アクセス解析も、異常を自動で知らせる仕組みも、一切ありません。**
> そのため **オーナーが毎朝見ることが、唯一の「気づく手段」** です。稼働開始（8/8）から始めてください。

---

## なぜ必要か（2分で読める背景）

このサイトの不具合には、**「エラーが出ないまま静かに壊れる」**種類のものがあります。

いちばん危ないのが **通知メール**です。

> **応募の通知メールは、届かなくても応募自体は成功します。**
> メールの送信だけが失敗し、その失敗はどこにも表示されません。

つまり **「メールが来ない ＝ 応募が無い」ではありません。** メール送信が壊れているだけかもしれず、その間の応募者は**誰からも連絡をもらえないまま放置**されます。求職者にとっては「応募したのに無視された」という体験になり、事業への影響が最も大きい壊れ方です。

**だから、メールを信用せず、必ず画面を見てください。**

---

## 毎朝やること（1分）

### 1. 管理画面を開く

```
https://yingpin.jp/admin
```

### 2. 上段の数字を見る

| 見る数字 | 何がわかるか |
|---|---|
| **新規応募（未対応）** | 連絡すべき応募が何件あるか |
| **未確認の会員** | WeChatで本人確認すべき人が何件あるか |
| **新規登録（7日間）** | 人が集まっているか |
| **公開中の求人** | 求人がちゃんと出ているか |

### 3. 一番下の「システム状態」を見る

| 表示 | 意味 |
|---|---|
| 通知メール **設定済み** | 送信先は設定されています（実際に届くかはテスト応募で確認） |
| 通知メール **未設定** | 🔴 **応募が来てもスタッフに通知が届きません**。Resendの設定が必要です |
| 回数制限 **共有ストア** | 設計どおりに効いています |
| 回数制限 **簡易（メモリ）** | 🟡 登録の回数制限がゆるいまま動いています（Upstashの設定で解消） |

### 4. 記録する

紙でもメモアプリでも構いません。**前の日と比べて極端におかしくないか**が分かれば十分です。

## こうなったら Claude に連絡してください

| 気づいたこと | 疑われること |
|---|---|
| 🔴 **通知メールは来ていないのに、管理画面には応募がある** | **メール送信が壊れている**（いちばん危険。すぐ連絡してください） |
| 🔴 応募が**3日以上続けて0件** | 応募の仕組みが壊れている／求人が見えていない |
| 🔴 新規登録が**急に止まった** | 登録の仕組みが壊れている／サイトに繋がらなくなっている |
| 🔴 「システム状態」が昨日と変わった | 設定が消えた可能性 |
| 🟡 画面にエラーが出る・表示が崩れている | そのまま画面をClaudeに見せてください |
| 🟡 会員から「応募したのに連絡が来ない」と言われた | 通知メールか応募の仕組みを確認します |

## 週に1回やること（3分）

- **応募のステータスを更新する**（`/admin/applications`）。連絡済みなら「連絡済み」へ。放置された応募が無いか確認します
- **未確認の会員をWeChatで確認する**（`/admin/members`）
- **求人の内容が最新か確認する**（募集が終わった求人は「停止」にする）
