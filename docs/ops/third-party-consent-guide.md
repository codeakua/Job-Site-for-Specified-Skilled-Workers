# 求人企業へ会員の情報を渡すときの手順（個別同意の取り方）

> **この手順でできること**: 職業紹介のために求人企業へ会員の情報を渡すとき、法律上必要な「会員本人の同意」を、**あとから証拠として示せる形**で取得できます。
> - **やる人**: 職業紹介を担当するスタッフ
> - **使うもの**: 管理画面の「応募管理」／WeChat
> - **かかる時間**: 会員1人・求人企業1社あたり 5〜10分
> - 判断に迷ったら、**送る前に**止めてオーナーに相談してください。**送ってしまってからでは取り返せません。**

**弁護士確認論点リストの D-5 に対応する手順書です。**

---

## 1. まず、いちばん大事なこと（1分）

### 🚨 「応募したこと」は「情報を渡してよい」という意味ではありません

会員が求人に応募するのは、**「この求人に興味があります」という意思表示**にすぎません。
**どの企業に・どの情報を渡すかについての同意は、応募とは別に、企業ごとに取ります。**

ここを混同して情報を送ってしまうと、**個人情報保護法第27条（本人の同意のない第三者提供）に違反**します。

### 当社が会員と交わしている約束

| どこに書いてあるか | 内容 |
|---|---|
| プライバシーポリシー 第4条第2項 | **あらかじめ会員の同意を得たうえで**、決められた範囲の情報を求人企業へ提供する |
| プライバシーポリシー 第4条第3項 | 同意は**求人企業ごとに**取得する。同意しない場合、その企業への紹介は行わない（他の求人への応募は妨げない） |
| 利用規約 第11条第2項 | 実際の雇用主の名称・就業場所は、**職業紹介を行う段階で会員に明示する** |
| 利用規約 第11条第4項 | 職業紹介にあたり、業務内容・契約期間・就業場所・賃金・労働時間・社会保険・受動喫煙防止措置などの**労働条件を明示する**（職業安定法第5条の3） |

サイトに掲示している文書なので、**守らなければ会員との約束違反にもなります。**

---

## 2. 渡してよい情報（2段階）

プライバシーポリシー 第4条第2項の表がそのまま基準です。**この表にない項目は渡しません。**

| 段階 | いつ | 渡してよい情報 |
|---|---|---|
| **第1段階** | 応募後、当社が職業紹介を行うと判断した時点 | 氏名、拼音、生年月日、性別、国籍、居住地区分、日本語能力（JLPT）、合格済みの特定技能分野、その他の資格・技能、**当社が作成した紹介状** |
| **第2段階** | 面接の日程調整が必要となった時点 | 上記に加えて、**連絡先（電話番号・WeChat ID）** |

### ⚠️ 渡してはいけないもの（表にないもの）

- **住所**（面接会場を決めるのに必要でも、まず会員に「都道府県まで伝えてよいか」を確認する）
- **メールアドレス**
- **他社の選考状況・応募履歴**
- **本人確認（WeChat）のやり取りの内容そのもの**
- パスワード（**そもそも当社も知りません**。ハッシュ化されていて誰も読めません）

> **第2段階を第1段階と一緒にやらないでください。** 連絡先は、面接をすることが決まってから渡します。先に渡すと、企業から会員へ直接連絡が行き、当社が把握できないやり取りが発生します。

## 3. 手順（5ステップ）

```
①紹介するか決める → ②会員に同意をお願いする → ③返事を待つ → ④記録する → ⑤企業へ渡す
                                                  ↑
                                   ここで「同意します」が来るまで、絶対に④⑤へ進まない
```

### ステップ1: 紹介するかどうかを決める

管理画面 → **応募管理** → ステータス「**新規**」の応募を開きます。
会員の資格・希望と求人の条件を見て、紹介するかどうかを判断します。

紹介しないと判断した場合は、ステップ2へ進まず、会員にその旨を伝えてステータスを更新します。

### ステップ2: 会員に「同意のお願い」を送る（WeChat）

**§4 の文面をコピーして使ってください。** 次の4点が抜けていると、同意として不十分です。

1. **求人企業の名称**（「大手食品メーカー」ではなく、正式名称）
2. **就業場所**
3. **渡す情報の項目**（§2 の表のとおり）
4. **断っても不利益がないこと**

あわせて、**労働条件（業務内容・契約期間・就業場所・賃金・労働時間・社会保険・受動喫煙防止措置）も同じタイミングで伝えます**（利用規約 第11条第4項・職業安定法第5条の3）。求人票をそのまま送るのがいちばん確実です。

### ステップ3: 返事を待つ

**「同意します」という明確な返事が来るまで、企業へは何も送りません。**

| 会員の反応 | 同意として扱えるか |
|---|---|
| 「同意します」「はい、お願いします」「同意」 | ✅ 同意 |
| 既読がついただけ | ❌ 同意ではない |
| スタンプ・絵文字だけ | ❌ 同意ではない（何に対する返事か分からないため） |
| 「考えます」「あとで返事します」 | ❌ まだ同意ではない |
| 無返信 | ❌ 同意ではない |

判断に迷う返事（「たぶん大丈夫です」など）が来たら、**もう一度はっきり聞き直してください。**

### ステップ4: 記録を残す

管理画面 → **応募管理** → 該当の応募を開く → **スタッフメモ**に、**§5 の形式で**記入します。

**この記録が、後から「同意を得ていた」ことを示す唯一の証拠**になります。記憶や口頭では証明できません。

### ステップ5: 情報を渡し、ステータスを更新する

同意された範囲の情報だけを企業へ送り、応募ステータスを「**連絡済**」（面接が決まったら「**面接**」）に更新します。
ステータスは**会員のマイページにも表示される**ので、会員から見ても進み具合が分かります。

## 5. 記録の書き方（コピーして使う）

管理画面「応募管理」の**スタッフメモ**に、**1行1件**で追記します。**上書きせず、下に足していきます。**

```
[同意依頼] 2026-08-20 14:30 / 企業=○○株式会社 / 就業場所=埼玉県富士見市 / 段階=第1段階 / 経路=WeChat
[同意取得] 2026-08-20 16:05 / 企業=○○株式会社 / 段階=第1段階 / 会員の返答=「同意」 / 担当=矢澤
[提供実施] 2026-08-20 17:20 / 企業=○○株式会社 / 項目=氏名・拼音・生年月日・性別・国籍・居住地区分・日本語能力・特定技能分野・その他資格・紹介状 / 方法=メール / 送付先=採用担当 ××様
```

### なぜこの形か

- **「いつ・どの企業に・何を・どうやって同意を得たか」が1行で追えます。** 弁護士・行政の確認や、会員からの問い合わせに即答できます
- **依頼・取得・実施を分けて書く**ことで、「同意を得る前に送っていないか」が一目で分かります
- 職業安定法第32条の15の**求人求職管理簿は2年間の保存義務**があります（→ 確認論点 B-5）。この記録もその一部として扱います

### ⚠️ 記録を後から書き換えないでください

誤りに気づいたときは、**元の行を消さずに、下に訂正行を足します。**

```
[訂正] 2026-08-21 09:00 / 上記「提供実施」の送付先は ××様ではなく △△様の誤りでした / 記入=矢澤
```

## 6. 同意が得られなかったとき

| 状況 | どうするか |
|---|---|
| **断られた** | その企業への紹介は行いません。**他の求人への応募は妨げません**（プライバシーポリシー 第4条第3項）。応募ステータスは「辞退」に。メモに理由を記入 |
| **返事がない** | **3営業日**待って、1回だけ確認の連絡を入れます。それでも返事がなければ紹介を見送ります。**無断で送ることは絶対にしません** |
| **一部だけ同意（例: 連絡先は渡したくない）** | 同意された項目だけを渡します。連絡先が渡せない場合は、**当社が間に入って日程を調整**します |

---

## 7. やってはいけないこと（重要）

1. **応募を同意とみなす** — §1のとおり、まったく別のものです
2. **まとめて同意を取る** — 「今後ご紹介するすべての企業について同意します」は、プライバシーポリシー第4条第3項（**企業ごと**）に反します
3. **§2の表にない項目を渡す**
4. **同意の記録を後から書き換える・消す**
5. **企業から「まず候補者の情報を送ってほしい」と求められて応じる** — 同意前は、**個人を特定できない形**（例: 「25歳・男性・外食業2号合格・N3」）でも慎重に。氏名・生年月日・拼音を含めた時点で第三者提供です
6. **口頭・電話だけで同意を取る** — 証拠が残りません。必ずWeChatなど文字が残る方法で

## 8. 会員から「やっぱり取り消したい」と言われたら

| 状況 | どうするか |
|---|---|
| **まだ企業へ送っていない** | 送りません。メモに記録します |
| **すでに送ってしまった** | **企業へ連絡し、情報の利用停止と削除を依頼します。** 依頼した日時と相手方をメモに記録します。当社は求人企業に対し「提供した情報を採用選考の目的以外に利用しない」ことを求めています（プライバシーポリシー 第4条第4項） |

## 9. 将来のシステム化について（担当者向けメモ）

現在は**スタッフメモへの手書き**で運用します。会員が画面上で同意ボタンを押す形にはなっていません。

同意記録のテーブル `member_consents`（2026-07-28 適用・D-2）は、種別として **`third_party`（第三者提供）を最初から受け付けられる**ようにしてあります。ただし「**どの求人企業に対する同意か**」を保持する列がまだ無いため、そのままでは企業ごとの同意を記録できません。

システム化する場合は、次の順で拡張します。

1. `member_consents` に「対象の応募（`application_id`）」を持たせる
2. 会員のマイページに「この企業への情報提供に同意する」ボタンを置く
3. スタッフ側は、同意が付いた応募だけ「提供済み」に進められるようにする

**確認論点 A-3 ①で、弁護士に「登録時の包括的な同意で足りるか」を確認中**です。「足りる」との回答であれば、この手順は大幅に簡素化できます。**回答が来るまでは、本手順（企業ごとの個別同意）で運用してください。**
