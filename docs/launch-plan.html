4スケジュールの2大注意点 ― 「順番」と「お盆」

⛓ 順番を守る作業（直列）
メール本番化：ドメイン購入 → DNS設定 → Resend独自ドメイン認証（信頼設定 SPF/DKIM/DMARC・反映最大48h）→ 送信元を自社に → 複数スタッフ宛。
→ ドメイン購入は今週（M0）に前倒し必須。今は送信元がテスト用でオーナー以外のスタッフに通知が届きません。
法務：規約・PP下書き → 弁護士 → 反映 → 公開。プライバシーポリシー公開は本格運用の前提条件。
🎌 お盆（8/11〜16頃）が最終盤に重なる
最終QA・予備日・弁護士の折返し・実求人企業への連絡が休みに直撃。→ 弁護士返却・実データ・企業連絡を「8/8まで」に前倒し、8/11〜16は予備＆軽作業に。

5AI・エフォート割り当て（使用量を節約しながら）

Claude Max（賢いOpus・枠多め）＋ ChatGPT Pro（Codexが主戦力）を賢く配分。品質を保ちつつ使用量を節約します。
賢さ＝「間違えたときの痛さ」で選ぶ
安全・設計・最終点検は最も賢いOpus。それ以外は標準のSonnetで十分。軽作業はHaikuやブラウザ版へ。
使用量＝「文脈の広さ×やり直し回数」
重要度とは別軸。1行の確認はOpusでも激安、「全部点検」は高い。だから作業は小さく区切る。既定はSonnet、安全時だけClaudeが自分でOpusへ。

使用量を節約する7つのコツ

  1. 依頼を具体的に書く（触る範囲・参照ファイル・完了条件）→ やり直し＝使用量の倍消費を防ぐ（最大の節約）
  2. Codex依頼に「完了条件チェック」を必ず付ける（差し戻しを無くす）
  3. 自動チェック(CI)を入れる→ 毎回の lint/build 確認が不要に（費用対効果が最も高い）
  4. レビューは変更点(差分)だけ渡す／⑤ 1作業=1会話で続ける（再読込コスト約1/10）
  5. 文章・翻訳・下書き・手順調べはブラウザのChatGPT/Claude（コーディング枠を使わない）
  6. 決めたことは docs/ に記録（同じ説明を繰り返さない）

7運用基盤 ― 公開後に事故らないための土台

「サイトが動く」だけでは足りない、"落ちても・壊れても立て直せる"仕組み。1人運営だからこそ必須。
土台何のためやること
本番ブランチ保護壊れたコードが勝手に本番へ出るのを防ぐ本番=保護されたmain。日々は別ブランチ→PR→プレビュー確認→合流。直接書き込まない
自動チェック(CI)壊れたまま公開を防ぐGitHub Actionsで lint&build 自動。失敗したら合流不可
監視3点落ちても気づくSentry（エラー通知）＋外形監視（5分毎・落ちたら通知）＋通知先=あなた
バックアップデータを失わないSupabase Pro（毎日＋時点復元）必須。公開前に復元を1回試す
戻す手順公開日に問題が出ても復旧Vercelの「1クリックで直前に戻す」を練習しておく
適用記録(台帳)何をDBに入れたか迷わない本番に流したSQLを順に記録。サンプル求人の削除手順も明記

8公開前セキュリティ是正（必須）

★＝データベース設定を直接確認して"実在"を確かめた穴。「あれば良い」ではなく公開の合格ラインです。
★ 今すぐ直す（弁護士不要）
  • ★ スタッフの内部メモが会員に見える（応募のスタッフメモを会員が直接読める）→ 会員から見えないよう分離
  • ★ 本人確認フラグを会員が自分で書き換えられる（唯一の本人確認の仕組みが無効化）→ スタッフだけ変更可に
  • 仮の文言を消す（「モックです／サンプル／98%以上」が残存）→ 撤去し実データに差替
  • 迷惑登録(bot)対策（回数制限＋ワナ。中国は画像認証が届かないためサーバー側制限を優先）
  • 管理鍵の記載削除・パスワード強度・管理操作の二重ガード・セキュリティヘッダ・不正転送対策・退会/削除対応

11法務・コンプライアンス確認項目（顧問弁護士へ）

Claudeは下書き作成まで。最終判断は弁護士に委ねます（以下は論点提示）。
  • 個人情報保護法：利用目的の公表（法21条）／委託先（Supabase・Vercel・Resend）明記／保管期間／開示・訂正・停止・苦情の窓口をプライバシーポリシー実ページに
  • 越境移転（法28条）：まずSupabaseの保管リージョンを確定 → 国名・制度・安全管理措置を示し同意取得が要るか確認
  • 同意の取り方：規約・PPへのリンク＋同意した日時・版数の記録で足りるか
  • 景品表示法：「98%以上」等の根拠、モック/サンプル表記の撤去
  • 職業安定法：労働条件明示（受動喫煙防止措置ほか）・取扱職種の範囲・手数料（求職者無償）・苦情処理体制の明示、実雇用主/就業場所の明示タイミング
  • 中国在住者の直接募集の適法性（労働局届出・中国国内の募集方法）／退会・消去請求への対応水準
