## 制約

- デザインはモック（リポジトリ直下のHTML群）のトークンに合わせる。**スマホ幅390pxで崩れないこと**
- 文言は日本語・中国語の両方をキーで持つ（`app/src/lib/i18n/dictionaries.ts`）。ただし**条文の本文そのものを dictionaries.ts に入れるのは避けてください**（数万文字になり、辞書の見通しが壊れます）。別の持ち方を設計してください
- Google系サービスは使わない（中国からのアクセスを考慮した方針）
- 完了前に `cd app && npm run lint && npm run build` を通すこと
