# トップページ ヒーロー画像の生成ブリーフ（ChatGPT用）

作成日: 2026-08-04（T-20 エージェント型LPのフォローアップ）

## 進め方（往復ワークフロー）

1. オーナーが下の**プロンプトA案またはB案**をChatGPTにそのまま貼り付けて画像を生成する（気に入るまで何度でも再生成してよい）
2. できあがった画像ファイル（PNG）をチャットでClaudeに渡す
3. Claudeが `app/public/` に配置し、トップページのヒーロー右側（現在は自作SVGイラスト）へ組み込む→検証→コミット

## プロンプトA案（イラスト調・推奨）

> 背景が透明なPNGのイラストを1枚作成してください。サイズは正方形（1024×1024）。
>
> 内容: 20代の中国人の若い男性と女性の2人組。日本で働くことに希望を持って、明るい表情で少し斜め前を見ている。男性は製造業の清潔な作業服、女性は飲食・サービス業の清潔な制服。ポーズは自然で親しみやすく、自信が感じられるもの。
>
> スタイル: 小紅書（RED）で人気のある、洗練されたモダンなフラットイラスト。線がきれいで、色数を絞った上品な塗り。メインの差し色は明るいブルー（#1E6FFF に近い色）。アクセントとして桜の花びらを数枚散らす。背景の要素は入れず透明のままにする（人物と花びらのみ）。
>
> 禁止事項: 文字・数字・ロゴ・国旗は一切入れない。背景に建物や風景を入れない（透明のまま）。

- 透過にならなかった場合:「背景を完全に透明にして再生成してください」と追加指示
- 文字が混入した場合:「文字を一切入れずに再生成してください」と追加指示

## プロンプトB案（実写調）

> 明るく爽やかな実写風の画像を1枚作成してください。サイズは正方形（1024×1024）。
>
> 内容: 20代の中国人の若い男性と女性が、日本の清潔で近代的な職場（明るい工場のライン、またはきれいな飲食店）で、自信のある自然な笑顔で立っている。自然光が入る明るい雰囲気。服装は清潔な作業服・制服。
>
> トーン: 透明感のあるブルー基調。彩度は上げすぎず、信頼感と希望を感じる仕上がり。構図は上半身中心で、被写体がはっきり分かるもの。
>
> 禁止事項: 文字・数字・看板の文字・ロゴは一切入れない。

- B案は背景透過にできないため、サイトでは**角丸カード＋影**の形で組み込む（Claude側で対応）

## 生成時のチェックポイント

- [ ] 文字・ロゴが入っていない（AI画像は文字が崩れやすいため必須チェック）
- [ ] 顔・手が不自然に崩れていない
- [ ] 明るく、希望が感じられる表情になっている
- [ ] （A案）背景が透明になっている

## 用途の約束（重要）

- この画像は**イメージビジュアル**として使う。実在の担当者・会員と誤認させる文脈（担当者紹介・利用者の声・実績写真など）には**使わない**
- 組み込み時は装飾画像として `alt=""`（スクリーンリーダー向けに読み上げない）

## 受領後の組み込み手順（Claude作業メモ）

1. `app/public/hero-visual.png` に配置（目安300KB以下へ圧縮・必要ならリサイズ）
2. `app/src/components/Landing.tsx` の `<HeroArt />` を `<img src="/hero-visual.png" alt="" width={800} height={800} />` に差し替え（生imgタグ＝`wechat-qr.png` と同じ慣習。旧SVGはgit履歴に残る）
3. B案（実写）の場合は `globals.css` のlp-ブロックに角丸カード用 `.lp-hero-photo` を追加
4. モバイル表示は実画像を見て判断（第一候補はPCのみ表示。主CTAがファーストビューから押し出されないことを優先）
5. `npm run lint && npm run build` → Playwright（390/1280×日中）→ コミット・プッシュ

## 結果（2026-08-04 組み込み完了）

- 画像はチャット添付で受領（ディスクに残らないため会話トランスクリプトのattachmentレコードからWebPを抽出）。A案・B案とも仮組みしてスクショ比較→**B案（実写・食品工場の男女）を採用**
- 実体は `app/public/hero-visual.webp`（1254×1254・約94KB・受領形式のWebPをそのまま使用）。カードスタイルは `.lp-hero-photo` を新設せず `.lp-hero-art img` に直接指定（白フチ4px＋`var(--r-xl)`＋`var(--shadow-float)`）
- 不採用のA案イラストは将来の差し替え候補としてこのブリーフのプロンプトで再生成可能
